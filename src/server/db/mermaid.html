    categories {
        TEXT slug PK "e.g. fruits-vegetables"
        TEXT name UK
        TEXT image "photo URL"
        INTEGER position "display order"
        INTEGER featured "0 or 1: shown on the home page"
    }

    products {
        TEXT id PK "e.g. ts4"
        TEXT brand
        TEXT name
        TEXT category_slug FK "categories.slug"
        TEXT unit "e.g. 1kg"
        INTEGER price_cents "> 0"
        INTEGER old_price_cents "NULL = not on sale"
        REAL rating "0 to 5"
        INTEGER reviews
        TEXT image "photo URL"
        INTEGER stock ">= 0"
        INTEGER sold_week "Best Seller ranking"
        INTEGER sold_month
        TEXT created_at "ISO time, New Arrivals order"
    }

    product_details {
        TEXT product_id PK, FK "products.id"
        TEXT description
        TEXT origin
        TEXT storage
        TEXT highlights "JSON array of strings"
    }

    deals {
        TEXT product_id PK, FK "products.id"
        INTEGER sold "units sold today"
    }

    banners {
        TEXT id PK
        TEXT placement "hero | hero-side | promo | brand"
        TEXT eyebrow
        TEXT title
        TEXT subtitle
        TEXT brand
        TEXT image
        TEXT image_alt
        TEXT href "link target"
        TEXT cta_label
        INTEGER position
        TEXT starts_at "NULL = no start limit"
        TEXT ends_at "NULL = no end limit"
    }

    settings {
        TEXT key PK "e.g. delivery_fee_cents"
        TEXT value
    }

FromToCardinalityMeaning
categoriesproductsone to zero-or-manyEvery product belongs to exactly one category (products.category_slug). A category may be empty, like Coffees & Teas.
productsproduct_detailsone to zero-or-oneLong-form text for the product page. Deleted with the product (ON DELETE CASCADE).
productsdealsone to zero-or-oneA row means the product is in today's Top Saver. The window ends at midnight in settings.time_zone.

banners and settings stand alone: banners link to pages by URL (href), not by foreign key, and settings is a key/value list. Money is stored in integer cents and returned by the API as decimal dollars.
